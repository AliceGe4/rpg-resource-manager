
# RPG Crafting Organizer

A JavaScript-based crafting and resource management application for a custom tabletop RPG system.

## Features Implemented

- Create, edit, and delete crafting items.
- Assign multiple resource attributes to items.
- Create, edit, and delete crafting recipes.
- Define required resource quantities for recipes.
- Track whether recipes have been crafted.
- Dynamic tables for viewing items and recipes.
- Reusable modal system with support for nested modals.

## Technologies

- HTML
- CSS
- JavaScript

## Project Goal

Build a crafting management system that can determine which recipes are craftable based on available items, their resource attributes, and recipe requirements.
